# Translation glossary

Cliché is written in French (keys = French source text, `Resources/fr.lproj`). Every other language
must use the **same term for the same concept everywhere**, and **Apple's official macOS wording** for
system names (as shown in System Settings in that language).

| Concept (EN) | FR source | Notes |
|---|---|---|
| screenshot / capture (noun) | capture | One word for the image; don't alternate screenshot/capture/shot. |
| capture (verb) | capturer | |
| area capture | capture de zone | "area", not "region"/"selection". |
| fullscreen capture | capture plein écran | |
| window capture | capture de fenêtre | |
| scrolling capture | capture défilante | |
| repeat area capture | répéter la capture de zone | |
| delayed capture | capture différée | |
| text recognition (OCR) | reconnaissance du texte (OCR) | keep "OCR" and "QR". |
| editor | éditeur | the annotation window |
| thumbnail | vignette | the small preview after a capture |
| pin / pinned image | épingler / épingle | floating image above all windows |
| backdrop | fond (décoratif) | gradient behind the image |
| tool names | Sélection, Flèche, Ligne, Rectangle, Ovale, Texte, Main levée, Surligneur, Masquer, Projecteur, Loupe, Compteur, Règle, Recadrer | short nouns/verbs as in Preview/Keynote |
| conceal styles | Flou, Pixels, Effacer | blur, pixelate, erase |
| smart ruler | règle | |

| shortcut | raccourci | |
| Screen Recording (permission) | Enregistrement de l'écran | **Apple's exact System Settings label** |
| Accessibility (permission) | Accessibilité | Apple's label |
| System Settings › Privacy & Security | Réglages Système › Confidentialité et sécurité | Apple's labels |
| Open Anyway | Ouvrir quand même | Apple's label |
| Settings (app window) | Réglages | Apple's "Settings…" menu term |
| Quit | Quitter | Apple's menu term |

Rules: keep `%@`/`%lld` (use `%1$@` `%2$@` only if the order must change), `…` (single character),
`⌫ ⎋ ⌘ ⇧ › ·`, `cliche://` paths, "Cliché", "PNG", "JPEG", "OCR", "QR", "WCAG", "Vision", "MIT".
Tone: short, plain, macOS-like; sentence case in English; no exclamation marks.
