# Changelog

All notable changes to Cliché. Versions follow [Semantic Versioning](https://semver.org).
New entries go under **Unreleased**; `scripts/release.sh X.Y.Z` turns that section into the release notes.

## [Unreleased]

- Automatic nightly DMG on every push to `main` (pre-release "Nightly", stable download link).
- `scripts/release.sh` cuts a release in one command; release notes come from this changelog.

## [0.2.0] - 2026-10-17

- Cliché now speaks English, French, German, Spanish, Italian, Brazilian Portuguese, Japanese and Simplified Chinese, following your macOS language with English as fallback.
- Shortcuts show digits on every keyboard layout (⇧⌘1 instead of ⇧⌘& on AZERTY).
- Same labels in the app, README and demo video.

## [0.1.0] - 2026-10-17

- First release: area, fullscreen, window and scrolling capture; text and QR recognition.
- Editor with 14 tools: arrow, line, rectangle, oval, text, freehand with shape correction, highlighter, blur/pixelate/erase, spotlight, magnifier, counter, smart ruler, crop; backdrops.
- Thumbnail after capture, pinned images, configurable global shortcuts, opt-in `cliche://` links.
